# Glossary

Version: 1.0.0

Status: Approved

---

# Activity

Any organized event created inside Pokatuha.

Examples:

- MTB ride
- XC ride
- Hiking
- Gravel ride
- Road ride

---

# Organizer

User who creates an activity.

The organizer manages:

participants

route

polls

chat

event settings

---

# Participant

A user who joins an activity.

---

# Ride

An active outdoor event.

---

# Archive

Completed activities stored locally.

Contains:

chat

photos

videos

GPX

statistics

votes

timeline

---

# Stage

A predefined phase of an activity.

Examples:

Preparation

Meeting

Ride

Break

Finish

Archive

---

# Live Mode

Application state where users exchange data using WebRTC/P2P.

Provides:

GPS

chat

events

votes

presence

---

# Sleep Mode

Application is inactive.

Wake-up is performed using Firebase Cloud Messaging.

---

# Offline Mode

No internet connection.

The application stores changes locally.

Synchronization resumes automatically after connectivity returns.

---

# GPX

GPS track file.

Used for exporting and importing routes.

---

# Event Chat

Chat associated with a single activity.

Messages belong to the activity archive.

---

# Poll

Voting system inside an activity.

Supports:

single choice

multiple choice

custom options

---

# Route

The planned or recorded path of an activity.

---

# Meeting Point

Location where participants gather before the activity.

---

# Arrival Notification

Automatic notification triggered when a participant approaches the meeting point.

Example:

"Alex is 500 meters away."

---

# Map Provider

Map rendering engine.

Default:

OpenStreetMap

MapLibre

---

# Weather Provider

Current implementation:

Open-Meteo

---

# AI Documentation

Documentation structured specifically for AI coding assistants.
