# Mission

Pokatuha is a privacy-first platform for organizing outdoor activities.

The application enables groups of people to create, coordinate and manage rides without requiring centralized storage of personal information.

The project is designed around one core idea:

> Users own their own data.

---

# Vision

Current ride planning applications usually require:

- cloud storage
- centralized chat
- centralized GPS
- centralized user database
- permanent internet connection

Pokatuha intentionally follows another direction.

All important user data remain on the user's own device.

The cloud is optional and should never become mandatory.

---

# Core Goals

## Privacy

The application must collect the minimum amount of personal information possible.

Default behaviour:

- local storage
- local archive
- local photos
- local GPX
- local history

---

## Reliability

A ride must continue even if:

- internet connection is lost
- cloud services become unavailable
- the developer's infrastructure is offline

---

## Simplicity

The application should remain understandable for beginners while providing professional tools for experienced users.

---

## Extensibility

Every major feature must be implemented as an independent module.

Examples:

- Chat
- Maps
- Weather
- GPX
- GPS
- Archive
- Voting
- Notifications
- Statistics

---

## Longevity

Pokatuha should remain maintainable for many years.

The architecture should avoid unnecessary complexity.

---

# Product Philosophy

Pokatuha is not another messenger.

Pokatuha is not another GPS tracker.

Pokatuha is not another social network.

Pokatuha is an activity coordination platform.

Communication, navigation and event management are equally important.

---

# Target Users

Primary audience:

- MTB riders
- XC riders
- Gravel riders
- Road cyclists
- Enduro riders
- Downhill riders

Secondary audience:

- hikers
- runners
- ski groups
- motorcycle groups
- kayaking groups

---

# Future Expansion

The architecture should allow additional modules without redesigning the system.

Possible future modules:

- bike maintenance
- equipment inventory
- public events
- club management
- race timing
- wearable integration
- bike computer synchronization

---

# Non Goals

Pokatuha is NOT intended to become:

- Facebook
- Telegram
- WhatsApp
- Instagram

Social networking features must never dominate the application's original purpose.
