# User Stories

Version: 1.0.0

Status: APPROVED

---

# Purpose

This document describes the application from the user's perspective.

Each User Story follows the format:

As a...

I want...

So that...

---

# US-001

As a cyclist

I want to create a ride

So that my friends can join it.

---

# US-002

As an organizer

I want participants to receive automatic invitations

So that I do not need to contact everyone manually.

---

# US-003

As a participant

I want to accept or decline an invitation

So that the organizer knows whether I will attend.

---

# US-004

As a participant

I want to see who has already joined

So that I know who will ride with me.

---

# US-005

As a participant

I want a dedicated chat for every ride

So that messages do not mix with other rides.

---

# US-006

As a participant

I want to see riders approaching the meeting point

So that I know when to prepare.

---

# US-007

As a participant

I want automatic notifications:

"Alex is 500 m away"

"John is arriving"

"Maria has arrived"

So that I don't constantly watch the map.

---

# US-008

As a participant

I want to share my GPS only after pressing Start

So that my location remains private before the ride.

---

# US-009

As an organizer

I want to create polls

So that the group can vote on:

- meeting time
- meeting location
- route
- ride distance
- ride difficulty
- custom questions

---

# US-010

As a participant

I want the completed ride to move into the archive automatically

So that I can review it later.

---

# US-011

As a participant

I want to export the GPX track

So that I can use it in other applications.

---

# US-012

As a user

I want to customize the application's appearance

So that the interface matches my preferences.

---

# US-013

As a user

I want to choose my preferred map provider

So that I can use the maps I like.

---

# US-014

As a participant

I want the application to continue working without internet

So that my ride is not interrupted.

---

# US-015

As a participant

I want synchronization to happen automatically after reconnection

So that I never lose data.

---

End of document.
