# UUID Policy

Version: 1.0.0

Status: APPROVED

---

# UUID Standard

Pokatuha uses UUID Version 7.

Reason

Chronological ordering

High performance

Distributed generation

No central server

---

# Generation

UUID is generated locally.

Never request IDs from external services.

---

# Usage

Every entity has exactly one UUID.

UUID never changes.

UUID is immutable.

---

# Import

Imported GPX

Imported Photos

Imported Activities

Receive new local UUIDs.

Original identifiers may be stored separately.
