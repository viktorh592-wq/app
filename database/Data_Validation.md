# Data Validation

Version: 1.0.0

Status: APPROVED

---

# Purpose

Guarantee consistent local data.

---

# Validation Rules

Required fields cannot be null.

Strings must be trimmed.

Dates must be valid UTC.

Latitude

Range

-90 to +90

Longitude

Range

-180 to +180

Speed

Cannot be negative.

Battery

0–100%

---

# Message Validation

Maximum message length configurable.

Empty messages forbidden.

---

# Poll Validation

Poll must contain at least two options.

---

# Route Validation

Route must contain at least one point.
